# PokeApp

PokeApp is an Android application developed with Kotlin and Jetpack Compose that consumes data from the PokeAPI to display information about Pokémon. The project was built to practice modern Android development concepts, including MVVM architecture, API integration, state management, and reusable UI components.

## Features

- Login screen
- Pokémon list
- Search by name
- Pokémon details
- Type badges
- Base stats visualization
- Responsive UI with Jetpack Compose
- API integration with PokeAPI

## Technologies

- Kotlin
- Jetpack Compose
- Material 3
- MVVM
- Retrofit
- Kotlin Coroutines
- StateFlow
- Coil
- Navigation Compose

## API

The application uses the public PokeAPI.

https://pokeapi.co/

## Getting Started

Clone the repository:

git clone https://github.com/mattheusramos/PokeApp.git

Open the project in Android Studio and run it on an emulator or Android device.

## Learning Objectives

This project was developed to practice:

- Modern Android development with Jetpack Compose
- MVVM architecture
- REST API consumption with Retrofit
- Navigation between screens
- State management with StateFlow
- Building reusable UI components
- Clean project organization
